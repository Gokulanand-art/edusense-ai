## Quick Start (2 minutes to running)

```bash
git clone https://github.com/your-username/smart-campus-intelligence-system
cd smart-campus-intelligence-system
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # fill in DB creds + JWT_SECRET + SECRET_KEY
python app.py          # migrations run automatically
python scripts/seed_data.py
```

App runs at **http://localhost:5000**

## Key Talking Points for Interviews

### Security
> "The JWT is stored only in an HttpOnly cookie — JavaScript cannot read it, which eliminates XSS-based token theft. The server validates the cookie on every request and checks a `jwt_blacklist` table for revoked tokens."

### Multi-tenancy
> "Every table has `institution_id`. The JWT payload carries the tenant's ID — so a student at DEMO campus physically cannot query data scoped to another institution even if they craft a request manually. Tenant isolation is also regression-tested."

### Readiness Score
> "The placement readiness formula is weighted: attendance 30%, marks 40%, skills 20%, mock tests 10%. The company matching engine compares a student's live score against each company's published minimums and surfaces the gap — 'you're 8 points from Infosys.'"

### Production Hardening
> "Health checks at `/health/live` and `/health/ready` are the Render readiness probe endpoints. The app has connection pooling, rate limiting on auth endpoints, security headers (CSP, HSTS, X-Frame-Options), structured request logging with IDs, and 85 automated tests."

### Tradeoffs I made consciously
> "Media is stored as BYTEA in Postgres — not ideal at scale but Render's free tier has an ephemeral filesystem. The ADR documents the migration path to S3. Background jobs are in-process simulations because there's no Redis on free tier — the ADR documents how to migrate to Celery."

## API Quick Reference

```bash

# Auth (cookie set automatically)
curl -X POST https://your-app.onrender.com/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"admin@smartcampus.edu","password":"password123"}' \
  -c cookies.txt

# Student dashboard (uses cookie from above)
curl https://your-app.onrender.com/student/dashboard -b cookies.txt

# Admin CSV export
curl https://your-app.onrender.com/admin/exports/students -b cookies.txt -o students.csv
```

## Render Deployment

1. Fork this repo
2. Go to [render.com](https://render.com) → New → Blueprint
3. Connect your fork → Render auto-reads `render.yaml`
4. Set these secrets in the Render dashboard:
   - `JWT_SECRET` — auto-generated by render.yaml
   - `SECRET_KEY` — auto-generated
   - `GEMINI_API_KEY` — optional, enables AI advisor
   - `SMTP_USERNAME` / `SMTP_PASSWORD` — optional, enables OTP email
5. Click Deploy — migrations run at startup automatically

**Post-deploy smoke test:**
```bash
bash scripts/verify_deployment.sh https://your-app.onrender.com
```
